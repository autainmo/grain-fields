# Quality Control

本文件负责判断生成结果是否合格，并规定失败后的定点修正。质检必须针对可观察结果，不使用“高级”“好看”等模糊标准。

## 1. 总体验收条件

默认任务只有在以下条件同时满足时才完成：

- 共 4 张完整方案图；
- 方案 1–3 视觉方向明显不同；
- 方案 4 保持原图配色和构图；
- 四个方案的配色类型彼此不同；
- 四个方案的文本类型彼此不同；
- 每张图都有 2–3 个基于内容的背景区域；
- 每张图都有一个面积大、连续完整的大颗粒区域；
- 颗粒单元在正常观看下明显可见；
- 主要主体可辨且结构稳定；
- 主要主体有清晰轮廓线；
- 文字若存在则可读、位置合理、事实无编造；
- 画面具有粗—净、密—疏对比与呼吸感；
- 若属于再次生成，新一组 4 个方案与本轮此前方案明显不同，且用户指定项被准确保留。

## 2. 输出数量检查

### 合格

- 默认 4 张；
- 每个方案 1 张；
- 四张均为完整成图。

### 不合格

- 只输出分析文字；
- 只输出 1–3 张；
- 把四个方案拼成一张不可独立使用的拼图，除非用户明确要求拼图；
- 其中某张只是色卡、草图或局部示意。

### 修正

只补生成缺失方案，不重做已合格方案。

## 3. 主体完整性检查

逐项检查：

- 主体身份 / 类别是否正确；
- 人物五官是否仍可辨；
- 人物数量是否正确；
- 建筑结构是否被改坏；
- 动物种类与身体结构是否正确；
- 车辆 / 器物结构是否正确；
- 主体姿态、朝向、比例是否与原图一致或在允许范围内；
- 用户未要求主体重构时，主体是否基本保持原图形，只进行了轻微的影调与颜色参数微调，而没有明显风格化、形变、材质替换或强烈改色；
- 关键标志色是否在需要时保留。

任何核心项明显失真都判定为不合格。

### 修正

- 强化“以源图为唯一主体依据”；
- 删除会诱导模型换主体的风格词；
- 明确锁定人物五官 / 建筑轮廓 / 物体结构；
- 不同时修改配色和颗粒参数。

## 4. 背景内容分区检查

### 合格

- 2–3 个主要背景区域；
- 每个区域对应真实、连续的内容或材质层；
- 边界跟随场景关系；
- 同一完整主体没有被机械拆分。

### 不合格迹象

- 纯粹左 / 中 / 右三块；
- 纯粹上 / 中 / 下三块；
- 一个完整人物被不同色块从身体中间切开；
- 同一建筑被无理由分成两种区域；
- 为凑第三块而新增一个小碎片区。

### 修正

回到 `01-scene-analysis.md` 重做内容地图，只改分区与边界描述。

## 5. 核心大颗粒区检查

这是本 Skill 最重要的质检项之一。

### 5.1 面积

合格：

- 是一个完整背景区域；
- 连续、成片；
- 通常约占整图 1/3–1/2，内容允许时可更大；
- 第一眼能感到它是画面中的主要材质块面之一，并已在不破坏主体与场景关系的前提下尽可能强化颗粒可见度；
- 应尽可能优先使用与主要主体直接相邻、紧挨主体的完整背景板块；只有相邻区域明显不满足面积、连续性、主体安全、文字避让或当前方案适配时，才允许改选其他完整背景区域。若分区呈左中右、上中下或中心被外围包围的中间结构，则应优先选择中间分区。

不合格：

- 只占边角；
- 只是一条窄边；
- 只覆盖背景的一小块；
- 多个小颗粒块零散分布；
- 颗粒区与主文字完全重叠；
- 颗粒只覆盖所选分区的一部分，而没有作用到整个选定分区。

### 5.2 颗粒尺寸

合格：

- 正常观看时能直接看到独立颗粒 / 大网点 / 粗半色调单元；
- 远看是明显材质，近看有颗粒结构；
- 不是透明噪声。

不合格：

- 只有细小沙点；
- 只有轻胶片颗粒；
- 缩小图后完全看不出颗粒；
- 看起来只是普通照片加噪声。

### 5.3 粗颗粒质感

合格：

- 颗粒重构了该区域；
- 原区域大体结构仍能辨认；
- 明暗变化能影响颗粒密度；
- 颗粒视觉强度明显高于其他区域。

不合格：

- 颗粒像覆盖层，底下仍是完全清晰照片；
- 所有区域同样粗糙；
- 颗粒没有主次。

## 6. 大颗粒失败修正梯度

按顺序只修一到两项，不一次全部放大：

### G1：颗粒太细

- 将颗粒单元尺度提高约 1.5–2 倍；
- 明确使用“粗颗粒 / 大网点 / 大尺寸半色调”；
- 删除“细腻胶片颗粒”“轻微噪点”等冲突词。

### G2：颗粒不够显眼

- 提升颗粒与区域底色的明暗差；
- 提升大颗粒在区域内的覆盖连续性；
- 降低其他区域纹理强度。

### G3：颗粒区太小

- 把处理范围扩展到当前完整语义区域；
- 若该区域天然过小，重新选择面积更大的完整候选区；
- 不跨越主体硬扩张。

### G4：颗粒变成表面滤镜

- 改写为“该区域整体由大颗粒重新组织”；
- 明确细节被概括进颗粒结构；
- 降低底层照片细节清晰度，仅保留大体轮廓与明暗。

### G5：颗粒区破坏呼吸感

- 保持核心颗粒强度不变；
- 清理其他区域多余纹理；
- 将主文字移到更干净区域；
- 通过颗粒边缘渐疏而不是整体降弱颗粒。

## 7. 配色方案检查

### 方案 1–3

必须检查：

- 是否真正脱离原图背景综合色进行重新设计；
- 是否给 2–3 个背景区域分别安排了完整配色；
- 三方案是否在至少两项维度显著不同：冷暖、明度、饱和、综合色相、对比方式、情绪；
- 四个方案的配色类型是否彼此不同，且方案 1–3 不与方案 4 的原图配色保留方向混同；
- 大面积背景色是否尽量避开主体最显著固有色；
- 主体重要标志色是否合理保留。
- 配色类型是否来自适配候选中的随机选择，而不是固定重复使用同一组合；
- 四个方案是否默认都保持原图尺寸与原图比例；
- 每个方案的核心大颗粒背景区域是否优先选择与主体相邻的区域；若分区呈左中右、上中下或中心被外围包围的中间结构，是否优先选择中间分区。

判定失败：

- 三张只是同一配色换明暗；
- 三张都是同一综合色系；
- 只给整体加单色滤镜；
- 所有背景区同色，没有分区配色关系。
- 三个重新配色方案机械共用同一比例或同一颗粒区，而没有体现各自配色方案的独立选择。

### 方案 4

必须检查：

- 原图主配色是否保留；
- 原构图是否保留；
- 主体位置与比例是否保留；
- 主要景物关系是否保留；
- 是否只做质感、对比、清晰度等不改变综合色的优化。

如果方案 4 明显换色或重构构图，必须重做。

## 8. 主体轮廓线检查

合格：

- 沿真实主体外缘；
- 用户无明确要求时严格默认中粗纯白色单线，不因背景颜色自动换色；
- 线条清晰可见；
- 不吞没主体细节；
- 非发光、非多重彩边；
- 只有用户明确要求其他描边时才允许改变颜色、粗细或形式。

不合格：

- 用户无明确要求时未使用中粗纯白色单线；
- 轮廓太细看不见；
- 轮廓太粗遮住手指、五官、建筑细部等；
- 只描人物，不描作为主要主体的建筑 / 动物 / 车辆 / 器物；
- 出现霓虹发光边；
- 用户无明确要求时因背景颜色而擅自把中粗白色线条改成其他颜色。

## 9. 文字检查

### 用户提供文字

检查：

- 是否展示用户实际填写内容；
- 是否丢失重要字段；
- 是否擅自改写核心语义；
- 是否错误补造地点、日期、相机型号等事实；
- 主文字是否避开高密度颗粒区；
- 标题 / 副标题 / 正文层级是否清楚。

### 自动文字

检查：

- 是否与当前方案气质匹配；
- 是否与画面内容匹配；
- 是否过长；
- 是否写出无法确认的事实；
- 四个方案的文本类型是否彼此不同；
- 文本类型是否来自适配候选中的随机选择，并形成效果好的组合。

### 修正

- 事实错误 → 删除虚构信息，不用“模糊改写”掩盖；
- 难读 → 换到干净区或改文字色 / 字号；
- 过长 → 缩短到标题 + 极短说明；
- 与配色气质不符 → 从 03 的文本预设库重新选型。

## 10. 留白与呼吸感检查

合格：

- 颗粒区视觉重量明确；
- 其他区域有相对干净空间；
- 文字与主体之间不拥堵；
- 画面不是每一处都高纹理、高对比、高信息。

不合格：

- 所有区域都粗颗粒；
- 文字、主体、颗粒全部堆在同一区域；
- 所有空白都被装饰填满；
- 背景各区强度相同，没有视觉层级。

## 11. 比例与构图检查

默认：

- 四个方案默认均与原图比例一致；
- 主体没有被无必要裁切；
- 方案 4 构图没有改变。

用户指定新比例时：

- 主体关键部分仍完整；
- 通过文字区和留白适配，不靠粗暴裁主体；
- 方案 4 只做最小必要变化。

## 12. 禁止项扫描

生成后快速扫描是否出现：

- 机械色块切割；
- 同一主体被分区切断；
- 小而弱的颗粒；
- 细噪点冒充大颗粒；
- 主文字压在颗粒最密处；
- 方案 1–3 高度相似；
- 方案 4 改色；
- 主体身份改变；
- 虚构事实；
- 无关大型装饰；
- 主体轮廓线缺失。

命中任一核心禁止项，判定对应方案不合格。

## 13. 定点修正矩阵

| 失败问题 | 只修正什么 | 不要同时改什么 |
|---|---|---|
| 颗粒太小 | 放大颗粒单元、提高粗颗粒描述 | 不改配色与主体 |
| 颗粒区太小 | 扩到完整语义区或换更大完整区 | 不跨主体硬扩张 |
| 颗粒像噪点 | 改为区域整体重构、降低照片细节 | 不削弱区域面积 |
| 分区机械 | 重做语义区域边界 | 不改主体 |
| 三方案太像 | 重选不同配色赛道 | 不改颗粒区规则 |
| 方案4改色 | 强化原色和原构图锁定 | 不改其他合格效果 |
| 主体失真 | 强化源图与主体锁定 | 不重做全部风格 |
| 轮廓不明显 | 增加线宽或对比 | 不改主体形态 |
| 文字难读 | 移到干净区、调字号和文字色 | 不弱化核心颗粒 |
| 出现虚构事实 | 删除虚构字段 | 不替换为另一条猜测 |
| 画面太满 | 清理非核心区域纹理和装饰 | 不把核心颗粒变弱 |
| 再生成与前组过像 | 重选尚未使用的配色 / 颗粒区 / 文案方向 / 比例组合 | 不牺牲主体适配与用户硬约束 |
| 再生成擅改用户指定项 | 恢复用户指定项并只优化未指定维度 | 不用“更优”为理由覆盖用户要求 |

## 14. 完成判定

只有当 4 张方案均通过以下最终检查才输出：

- [ ] 四张齐全；
- [ ] 主体身份与结构稳定，且用户未要求主体重构时仅做轻微影调与颜色参数微调；
- [ ] 2–3 个内容背景区合理；
- [ ] 同一完整主体未被分区拆分；
- [ ] 每张都有一整块大面积粗颗粒区；
- [ ] 尽可能优先选择紧挨主体的完整背景板块作为颗粒区；
- [ ] 若分区呈左中右、上中下或中心被外围包围的中间结构，优先选择中间分区；
- [ ] 颗粒效果覆盖整个选定分区；
- [ ] 大颗粒第一眼可见且在安全范围内尽可能明显；
- [ ] 其他区域相对干净并有呼吸感；
- [ ] 主体轮廓线清晰；
- [ ] 四个方案的配色类型彼此不同；
- [ ] 四个方案的文本类型彼此不同；
- [ ] 四个方案默认均使用原图尺寸与原图比例；
- [ ] 方案 4 保持原图配色和构图；
- [ ] 文本可读且无虚构事实；
- [ ] 未命中总体禁止项；
- [ ] 若属于再次生成，新一组与本轮此前方案在可调整维度上有明确差异；
- [ ] 若再次生成时用户指定了配色、颗粒选区、文案或尺寸，指定项均被准确执行；
- [ ] 新一组每个方案的配色、颗粒选区、文案、尺寸与主体关系仍为当前约束下的最优搭配。
