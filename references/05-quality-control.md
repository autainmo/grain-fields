# Quality Control

本文件负责判断生成结果是否合格，并规定失败后的定点修正。所有标准必须可观察，不使用“高级”“好看”等模糊词作为唯一判断依据。

## 1. 总体验收条件

默认任务同时满足以下条件才完成：

- 共 4 张完整方案图；
- 方案 1–3 有明确差异但整体配色克制；
- 方案 4 保持原图主配色与构图；
- 每张图背景均按真实内容形成 2–3 个区域；
- 每张图都有一个完整、连续、适合该场景的颗粒区域；
- 颗粒单元为中等视觉尺度，不细成噪点，也不大成块状图形；
- 颗粒与原区域材质、明暗和空间关系自然融合；
- 主要主体可辨且结构稳定；
- 主体有清晰轮廓线；
- 文字若存在则可读、位置合理、事实无编造；
- 画面保留干净区域与呼吸感，没有过度装饰。

## 2. 背景分区检查

合格：

- 2–3 个主要背景区域；
- 每个区域对应真实、连续的内容或材质层；
- 边界跟随场景结构；
- 同一完整主体未被机械拆分。

不合格：

- 纯粹左 / 中 / 右或上 / 中 / 下切块；
- 为凑第三块新增小碎片；
- 完整人物、建筑、车辆、山体等被色块切开。

修正：`repair_target = 01-scene-analysis.md`。

## 3. 颗粒区域选择检查

合格：

- 是完整、连续的背景内容区；
- 选择理由与原区域材质、结构、主体关系相符；
- 颗粒化后仍能看出该区域是什么；
- 不与主要文字区严重冲突；
- 处理后视觉重量与主体平衡；
- 通常约占整图 1/4–1/2，但不为面积强行跨主体扩张。

不合格：

- 只是因为面积最大而选择，实际材质与构图并不适合；
- 颗粒区破坏主体边缘或关键空间关系；
- 为扩大面积把不相干区域硬拼在一起；
- 只在边角做小块点缀。

修正：优先 `repair_target = 03-art-direction.md`；若候选区分析本身错误，返回 `01-scene-analysis.md`。

## 4. 颗粒尺度检查

### 合格

- 正常观看能明显感知颗粒质感；
- 近看能分辨颗粒单元；
- 单颗粒不会成为画面中的独立大型几何块；
- 远看仍能保持原场景区域的整体识别；
- 颗粒视觉尺度整体处于中等范围。

### 太小 / 太细

迹象：

- 只像胶片噪点；
- 缩小后完全看不出颗粒；
- 像透明噪声层。

修正：`repair_target = 04-generation-compiler.md`，小幅提高颗粒尺度或对比，优先约 1.2–1.5 倍，不直接倍增到超大颗粒。

### 太大 / 太夸张

迹象：

- 形成大方块、大像素、拼豆、巨大马赛克砖；
- 单颗粒比主体局部结构还抢眼；
- 原区域被块状图形吞没；
- 有明显玩具、糖果、拼装感。

修正：`repair_target = 04-generation-compiler.md`，将颗粒尺度降低并改为中等、连续、随明暗变化的颗粒语言；必要时返回 `03-art-direction.md` 更换颗粒预设。

## 5. 颗粒自然融合检查

合格：

- 颗粒密度、方向或透明度能顺着原区域明暗和材质变化；
- 区域边缘自然过渡；
- 原区域大体轮廓、空间和层次仍可辨；
- 看起来像原场景发生了材质转译，而不是贴了一个纹理图层。

不合格：

- 颗粒像矩形贴纸；
- 原照片细节完全清晰，只叠了一层噪声；
- 边界生硬且与景物结构无关；
- 所有颗粒大小、方向、密度完全一致，缺少材质响应。

修正：`repair_target = 04-generation-compiler.md`；若颗粒预设本身不适配则返回 `03-art-direction.md`。

## 6. 配色检查

### 方案 1–3

必须满足：

- 各背景区域有清楚的色彩角色；
- 三案至少在冷暖、明度、综合色倾向、饱和度或对比方式中两项明显不同；
- 通常只使用 2–4 个核心颜色角色；
- 优先中低饱和、自然中性色与少量强调色；
- 大面积背景色不应吞没主体重要固有色；
- 局部细节色存在时面积小、目的明确。

判定失败：

- 高饱和颜色过多；
- 彩虹、多重霓虹、复杂渐变成为主视觉；
- 每个区域都用不同强色，导致画面碎裂；
- 为“差异化”刻意堆贴纸、图标、纹理与装饰；
- 三张只是同色系近似变化。

修正：`repair_target = 03-art-direction.md`，减少颜色数量，重建明度与冷暖关系，不修改主体与分区。

### 方案 4

检查原图主配色、构图、主体位置、比例与主要景物关系是否保留。若换色或改构图，返回 `04-generation-compiler.md`；上游未锁定则返回 `03-art-direction.md`。

## 7. 细节与装饰检查

允许：

- 少量与原材质相关的轻微色差；
- 颗粒边缘自然渐疏；
- 小范围印刷不均、纸面感、矿物感；
- 单一受控强调色。

不允许：

- 每个空白都填装饰；
- 多处贴纸、符号、图标、线条同时出现；
- 无关的大型文字装饰；
- 为了“设计感”添加画面中不存在的新物件；
- 细节比主体和颗粒区域更抢眼。

失败：`repair_target = 03-art-direction.md`。

## 8. 主体轮廓检查

合格：

- 沿真实主体外缘；
- 默认纯白；
- 清晰可见但不过粗；
- 非发光、非多层彩边；
- 浅背景白线失效时才换高对比单色。

失败通常返回 `04-generation-compiler.md`；若颜色选择错误则返回 `03-art-direction.md`。

## 9. 文字检查

- 用户文字是否完整保留；
- 是否擅自编造地点、日期、器材、人物身份等；
- 主文字是否避开颗粒最密区；
- 自动文字是否过长或过度装饰；
- 标题、副标题与正文层级是否清楚。

事实错误返回 `01-scene-analysis.md`；版式与文字方向问题返回 `03-art-direction.md`；只是 prompt 未落实则返回 `04-generation-compiler.md`。

## 10. 主体完整性检查

检查身份 / 类别、人物五官与数量、建筑结构、动物身体结构、车辆 / 器物结构、姿态、朝向、比例和必要标志色。

若上游识别错误：`repair_target = 01-scene-analysis.md`；若只是生成锁定不足：`repair_target = 04-generation-compiler.md`。

## 11. 最终快速扫描

任一项出现即不合格：

- 机械几何分区；
- 同一主体被切断；
- 颗粒细成噪点；
- 颗粒大成方块 / 大像素 / 拼豆 / 巨型马赛克；
- 颗粒像贴上去的纹理层；
- 颗粒区域选择明显不适合场景；
- 多重霓虹、彩虹、高饱和多色堆叠；
- 无意义装饰过多；
- 主文字压在颗粒最密处；
- 方案 1–3 高度相似；
- 方案 4 改色或改构图；
- 主体失真；
- 事实信息被编造。
