# Text Presets｜完整文本方案预设

## 9. 预设文本方案库

> 选择文本类型时先检查事实字段可用性。需要具体地点、时间、器材、身份等事实的方案，只能使用用户实际提供或可靠确认的信息。

### 纪实 / 信息说明

| 名称 | 简介 |
|---|---|
| 新闻标题式 | 用一句高信息密度标题概括画面核心事件或内容 |
| 报纸导语式 | 标题后接极简事实导语，快速说明人物、地点与事件 |
| 图片说明式 | 像新闻图片注释一样说明画面中发生了什么 |
| 新闻摄影图注 | 强调时间、地点、人物、事件与拍摄现场 |
| 纪实摄影说明 | 用克制客观语言描述主体与现场关系 |
| 档案记录式 | 以编号、时间、地点、对象等信息构成档案感文本 |
| 事件记录式 | 围绕某一事件的发生背景与现场状态进行简述 |
| 现场记录式 | 强调此时此地的现场性和即时性 |
| 时间地点记录 | 以日期、时间和地点为核心，其他信息极简 |
| 人物身份介绍 | 简洁说明人物姓名、身份、职务或角色 |
| 主体百科式 | 用一句定义加极简说明介绍建筑、动物、器物等主体 |
| 建筑信息照 | 建筑名称、地点、年代、设计者或用途等信息型排版 |
| 景观信息照 | 景观名称、地点、地貌或环境特点的极简介绍 |
| 动物观察记录 | 物种名称、地点、时间、行为状态等自然观察信息 |
| 植物观察记录 | 植物名称、地点、形态特征的简洁记录 |
| 器物档案 | 名称、年代、材质、用途等博物馆式信息 |
| 车辆档案 | 车型、年份、地点、参数等机械档案式文本 |
| 摄影作品信息 | 标题、地点、年份、摄影者等标准摄影作品信息 |
| 摄影信息照 | 地点、时间、相机、镜头、焦段、光圈、快门、ISO等摄影参数 |
| EXIF参数式 | 将拍摄参数作为主要文本内容，强调摄影属性 |
| 胶片信息式 | 胶卷、机身、镜头、冲扫方式等胶片摄影信息 |
| 航拍信息式 | 地点、高度、设备、时间等航拍记录 |
| 经纬度坐标式 | 以经纬度、海拔和地点作为核心信息 |
| 地理坐标档案 | 坐标、行政区、海拔、方位等地理信息组合 |
| 气象记录式 | 温度、天气、风速、湿度等环境数据辅助画面 |
| 旅行日志式 | 日期、地点、路线和极简感受组成旅行记录 |
| 行程节点式 | 把画面作为旅行路线中的一个节点进行说明 |
| 编号档案式 | 用编号、编号标题与短说明强化收藏或调查感 |
| 编年记录式 | 年份或日期作为视觉核心，配一两句事实说明 |
| 年表节点式 | 将画面作为某段时间线中的关键节点 |
| 标本标签式 | 学术标本标签般列出名称、地点、日期、编号 |
| 博物馆标签式 | 作品名、年代、材质、作者、馆藏式极简信息 |
| 展品说明牌 | 标题加一段极短说明，像展览现场说明牌 |
| 文献索引式 | 文献编号、标题、地点、日期等索引式信息 |
| 调查记录式 | 调查对象、时间、地点、观察结论等理性文本 |
| 勘察记录式 | 工程、建筑、地貌等现场勘察式说明 |
| 科研采样式 | 样本编号、地点、日期、条件等科研记录语言 |
| 赛事信息式 | 赛事名称、对阵、时间、地点、比分或选手信息 |
| 演出信息式 | 演出名称、艺人、场地、日期等演出档案 |
| 活动信息式 | 活动名称、地点、时间、参与对象等标准信息 |
| 会议记录式 | 会议名称、日期、地点、参加人员等正式信息 |
| 工作纪实式 | 项目名称、人员、地点、时间与工作状态 |
| 工程记录式 | 工程名称、节点、地点、日期等项目记录语言 |
| 施工节点式 | 施工阶段、时间、地点、工序等工程现场信息 |
| 试验记录式 | 试验名称、编号、条件、日期等实验档案文字 |

### 人物专题 / 肖像

| 名称 | 简介 |
|---|---|
| 人物姓名大标题 | 以人物姓名为核心，副标题说明身份或故事 |
| 人物传记式 | 姓名、年份和一句概括经历或性格的文本 |
| 人物档案式 | 姓名、身份、地点、日期等档案式介绍 |
| 人物专访式 | 像杂志人物专访封面，突出姓名与一句观点 |
| 人物特写式 | 聚焦人物某一状态或特征，用极简标题描述 |
| 人物故事式 | 用一两句短文暗示人物经历与处境 |
| 人物语录式 | 以一句有代表性的自述或观点作为主体文字 |
| 人物宣言式 | 用短而有力的第一人称句子强化人物性格 |
| 人物标签式 | 用几个关键词概括人物身份、性格或角色 |
| 人物关键词 | 姓名加3–5个简短关键词形成编辑感 |
| 职业肖像 | 职业名称、姓名、工作地点与简短说明 |
| 劳动者肖像 | 用朴素语言突出职业、动作和劳动现场 |
| 青年肖像 | 姓名、年龄或状态加简短青春表达 |
| 老人肖像 | 以岁月、经历、身份等为核心的克制文本 |
| 儿童肖像 | 简单轻盈童真，不堆砌成人化表达 |
| 女性人物专题 | 根据人物气质采用克制、力量或柔和专题语言 |
| 男性人物专题 | 根据人物状态突出力量、沉静或故事性 |
| 运动员专题 | 姓名、项目、成绩或竞技关键词组合 |
| 艺术家专题 | 姓名、创作领域和一句艺术观点 |
| 音乐人专题 | 姓名、作品或一句歌词感短句 |
| 摄影师专题 | 姓名、地点、器材或摄影观念组合 |
| 工匠人物专题 | 姓名、手艺、地点和一句技艺传承文本 |
| 学者人物专题 | 姓名、领域、机构和一句观点 |
| 历史人物专题 | 姓名、年代、身份与简洁历史背景 |
| 无名人物纪实 | 不强调姓名，以一个人、一种生活为核心 |
| 群像专题 | 用共同身份、地点或事件概括多人主体 |
| 世代群像 | 强调同一代人的共同经历与时代背景 |
| 城市人物 | 人物与城市关系为核心的专题文字 |
| 故乡人物 | 地方身份、生活状态和地域感并重 |
| 陌生人系列 | 编号、地点、日期和极短观察式文字 |

### 文学 / 诗意

| 名称 | 简介 |
|---|---|
| 诗词名句引用 | 选择与画面意境高度契合的古诗词名句 |
| 古诗意境式 | 不直接引用名句，以古典诗意语言描写画面 |
| 现代诗短句 | 用极短现代诗句表达画面情绪与空间 |
| 自由诗 | 使用分行、停顿与留白形成现代文学感 |
| 散文短句 | 用一两句具有画面性的散文语言补充叙事 |
| 文学旁白 | 像小说或电影旁白一样补充画面背后的故事 |
| 小说开头式 | 用一句具有悬念或故事感的开场文字 |
| 小说结尾式 | 像故事结束后的最后一句，带余味和留白 |
| 日记片段 | 日期加第一人称短句，私人而真实 |
| 手记式 | 比日记更克制，像旅行、观察或生活手记 |
| 信件片段 | 使用致某人或信件中的一句话增强情感 |
| 未寄出的信 | 带遗憾、克制和未完成感的第一人称文字 |
| 明信片文学 | 地点加一句可以写在明信片背面的短句 |
| 诗性地名 | 将地点作为情绪入口，写出极简地方文学 |
| 风景散文 | 围绕山川、海岸、城市进行简洁文学描写 |
| 山川文学 | 以山、河、云、风等自然元素构成雄浑或宁静文字 |
| 海岸文学 | 围绕海、潮汐、风与远方展开短句 |
| 城市文学 | 以街道、灯光、建筑和人群为核心写都市情绪 |
| 公路文学 | 道路、远方、速度、出发与自由感为核心 |
| 铁路文学 | 车站、轨道、远行、告别和抵达等意象 |
| 雨天文学 | 雨、窗、街道、声音构成安静或忧郁文本 |
| 风的文学 | 以风作为画面中的隐形叙事线索 |
| 光影文学 | 围绕光线、阴影、空间进行抽象表达 |
| 静物文学 | 从一个物品展开记忆、人物或生活联想 |
| 植物文学 | 通过植物生长与形态表达生命感 |
| 动物文学 | 以动物行为映射自由、孤独、陪伴等主题 |
| 建筑文学 | 从空间、墙体、窗户、旧痕写建筑与人的关系 |
| 古镇文学 | 以巷道、屋檐、青石、河道和旧生活为核心的地方文学 |
| 江南文学 | 水巷、雨、桥、白墙黛瓦等含蓄柔和语感 |
| 北方文学 | 风、土地、长路、旧城等偏厚重朴素文字 |
| 西部文学 | 荒原、公路、山脉、孤独和远方感 |
| 海岛文学 | 岛屿、海风、潮汐和距离感组成轻孤独文字 |
| 故乡文学 | 家乡、旧物、亲人、道路和记忆为核心 |
| 乡土文学 | 土地、村落、劳动和地方生活的朴素叙述 |
| 人间烟火 | 饭菜、街巷、灯火、人情等日常温度表达 |
| 岁月留痕 | 从旧物、建筑或人物状态写时间留下的痕迹 |
| 无常感 | 用克制文字表现变化、离开和不可重复 |
| 相逢文学 | 围绕相遇、偶然和短暂交集展开 |
| 告别文学 | 以离别、远去、最后一面为核心 |
| 重逢文学 | 强调时间之后再次相遇的复杂情绪 |
| 等待文学 | 围绕停留、等待、迟到与未知展开 |
| 远方文学 | 用远方表达向往、漂泊和未知 |
| 漂泊文学 | 关于陌生城市、旅途和无归属感的短句 |
| 归乡文学 | 从回家、旧路和熟悉景物中表达情绪 |
| 记忆碎片 | 用零散句式表现模糊、断裂的记忆 |
| 梦境旁白 | 现实与梦境之间的朦胧非逻辑文字 |
| 意识流短句 | 以感受和联想为主，弱化完整叙事 |
| 极简哲思 | 用极短句提出关于生活、存在等思考 |
| 存在主义 | 围绕孤独、选择、自由、意义等主题展开 |
| 生命感悟 | 从主体状态引出关于成长、衰老或生命的短句 |
| 时间哲思 | 围绕过去、现在、瞬间和流逝展开 |
| 空间哲思 | 通过距离、边界、内外、远近等空间关系表达 |

### 旅行 / 地方文化

| 名称 | 简介 |
|---|---|
