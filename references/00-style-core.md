# Style Core

## 1. 风格核心命题

真实主体保持稳定，背景按画面实际内容划分为 2–3 个语义完整区域，从中选择**最适合颗粒化的一整块背景区域**，使用自然、适中、不过度装饰的颗粒语言，与简洁克制的分区配色共同建立层次。

> **大面积颗粒区 ≠ 超大颗粒单元。** 颗粒处理区域应连续、成片、明显；单颗粒本身保持适中，既不能细到只剩噪点，也不能大到形成方块、拼豆或巨大马赛克。

## 2. 最终视觉身份

本 Skill 的稳定视觉结构：

- 主体可信、可辨、结构稳定；
- 背景按内容而不是几何位置分区；
- 每张图有一个连续的核心颗粒区域；
- 颗粒尺度适中，与原区域材质、明暗和结构自然融合；
- 主体以清晰外轮廓与背景分离；
- 方案 1–3 重新配色，但优先简洁、低干扰、耐看的色彩关系；
- 方案 4 保留原图色彩与构图；
- 文字若存在，进入版面逻辑而不是后贴标签。

## 3. Style Invariants｜风格不变量

1. **主体辨识稳定**：主体身份、类别、外形、结构、比例、姿态与关键细节不得因重构而失真。
2. **内容分区**：背景依据真实景物、空间层次、材质与连续结构归纳为 2–3 个主要区域，不机械上下左右切割。
3. **完整对象不拆分**：同一个完整主体或连续景物不得为了分区被强行切断。
4. **颗粒区必须成片**：核心颗粒区应是完整、连续、面积明显的背景区域，但不以“越大越好”为目标。
5. **颗粒尺度适中**：正常观看可明显感知颗粒质感，近看可辨认颗粒单元，但不得形成抢眼的巨型块面。
6. **自然融合优先**：颗粒必须顺着区域原有材质、明暗、方向和空间关系重构，不像贴上去的独立特效。
7. **主体轮廓分离**：主要主体沿真实外缘增加清晰轮廓线；默认纯白，浅背景失效时改用高对比单色。
8. **配色克制**：方案 1–3 需要差异，但通常控制在 2–4 个核心颜色角色；优先中低饱和、中性色、明确明度层级和少量强调色。
9. **文字服从画面**：主文字优先放在相对干净区域；事实信息不得编造。
10. **呼吸感**：核心颗粒区之外的背景保持相对干净，局部细节只作为辅助，不填满每个角落。

## 4. Source Role｜原图角色

- **S1 主体摄影保留**：优先保留主体真实外形、姿态、比例、材质与识别特征。
- **S2 场景语义地图**：海、天、地面、建筑、植被、墙体、道路、水面、岩石等真实内容决定分区边界。
- **S3 颗粒转译底稿**：选定背景区域保留大体轮廓、明暗与空间关系，细节被组织为适中颗粒结构。
- **S4 原图整体保留（仅方案 4）**：原图主配色、构图、主体位置、比例与景物关系为强锁定条件。

## 5. 颗粒区域与颗粒尺度

### 颗粒区域

- 优先选择语义完整、连续性好、与主体层次明确、文字冲突少、颗粒化后仍自然的区域。
- **适配性高于面积。** 通常约占整图 1/4–1/2；若最自然的区域略小，可保持真实边界。
- 不跨主体硬扩张，也不把多个无关区域为了面积强行拼在一起。

### 颗粒单元

- 典型视觉尺度可理解为图像短边约 0.2%–0.8%，随内容复杂度调整；通常不超过约 1.2%。
- 颗粒允许随原区域明暗改变密度、大小或透明度，但整体语言应统一。
- 远看仍是原场景中的一块背景，近看才看到颗粒结构。

## 6. 配色身份

自动模式下，方案 1–3 的配色应优先：

- 2–4 个核心颜色角色；
- 一个主背景基调 + 一个辅助色 + 一个可选强调色；
- 中低饱和或克制高饱和；
- 通过冷暖、明度、综合色倾向建立差异，而不是不断增加色相数量；
- 强调色面积小，不抢主体；
- 主体重要固有色保留，背景避免与主体最明显颜色融在一起。

局部可以有细节色、材质色差或轻微印刷变化，但只能服务主体与空间，不得刻意炫技。

## 7. 信息密度与留白

- 画面优先保持一个明确主视觉焦点。
- 核心颗粒区只选一个主要区域。
- 其他区域纹理强度低于核心颗粒区。
- 主要文字避开颗粒最密处。
- 自动生成文字优先短标题、短副标题、极短说明。
- 若背景已经复杂，应减少装饰而不是继续叠加细节。

## 8. 风格强度

- 主体保留强度：高。
- 背景重构强度：中等至中高。
- 核心颗粒区：明显但自然，不追求最大颗粒或最强冲击。
- 其他背景区纹理：低。
- 配色：克制、中等强度，强调色受控。
- 方案 4 配色变化：零。

## 9. Hard Avoids｜绝对禁止项

- 机械二等分、三等分画面；
- 将同一人物、建筑、山体、车辆或连续景物硬拆成多个区域；
- 只在边角放小颗粒块冒充核心颗粒区；
- 颗粒细到只剩胶片噪点或透明滤镜；
- 颗粒大到形成大方块、大像素、拼豆、巨大马赛克砖或巨型几何块；
- 玩具感、糖果感、拼豆感、过强手工拼装感的颗粒语言；
- 所有背景区域都同样粗糙；
- 多重霓虹、彩虹、高饱和多色堆叠；
- 过度渐变、过多装饰符号、贴纸或无意义纹理；
- 主体轮廓线过细不可见或过粗吞没细节；
- 方案 1–3 只是同一配色的近似变化；
- 方案 4 改变原图综合色、主要构图或主体位置；
- 颗粒覆盖主文字；
- 为艺术感改变主体身份、结构或类别；
- 自动编造用户未给出的事实信息。
