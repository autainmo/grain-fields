# Grain Presets｜完整大颗粒重构预设

> 所有预设都必须满足同一硬条件：处理区域足够大，颗粒单元足够大，缩略观看仍能明显识别颗粒结构；不得退化成细噪点或轻纹理。

## 1. 印刷 / 油墨类

| 大颗粒方案 | 简介 |
|---|---|
| 印刷缺失 | 大块油墨未印上，形成不规则空缺 |
| 缺墨斑块 | 色块内部出现明显颗粒状断墨 |
| 掉墨 / 脱墨 | 像旧印刷品表面油墨脱落 |
| 漏印 | 局部图形直接缺失 |
| 残印 | 只留下断断续续的主体轮廓 |
| 粗网点印刷 | 放大的圆形印刷网点 |
| 超大半调网点 | 人物或背景被巨大圆点构成 |
| 方形网点 | 方形颗粒形成明暗 |
| 菱形网点 | 菱形颗粒排列 |
| 线状网屏 | 粗线条代替连续色调 |
| 双色套印颗粒 | 两种大颗粒颜色错位叠印 |
| 套色偏移 | 红蓝黄等色版明显错位 |
| 丝网漏墨 | 色块带大面积孔洞和边缘缺失 |
| 丝网印刷粗颗粒 | 厚重、块状、边缘粗糙 |
| 孔版印刷颗粒 | 类似油印、蜡纸印刷的不均匀块面 |
| Riso 粗颗粒 | 孔版油墨不均匀＋套色错位 |
| 橡皮章缺印 | 印章式大片不完整着色 |
| 旧报纸粗网点 | 放大的新闻印刷点阵 |
| 油墨堆积 | 局部墨量过重形成凝聚块 |
