# Grain Presets｜克制颗粒预设

本库只提供**自然、适中、可与真实场景融合**的颗粒语言。它不是为了制造夸张特效，而是为 `03-art-direction.md` 提供可选的颗粒方向。

> 颗粒区可以是大面积连续区域，但单颗粒尺度必须适中。禁止大方块、大像素、拼豆、巨大马赛克砖、巨型几何块、玩具感颗粒和过度装饰性颗粒。

## 使用原则

1. 先由 `01-scene-analysis.md` 完成背景分区与颗粒候选区评分，再选择颗粒预设。
2. 区域适配性优先于预设新奇度；不能为了套效果改变场景语义边界。
3. 自动模式优先选择最自然的一种，不要求四个方案强行使用四种不同颗粒。
4. 单颗粒通常保持中等视觉尺度：正常观看可感知，近看可辨认，但不形成抢眼的大型块面。
5. 颗粒密度可随原区域明暗、材质方向和空间层次变化。
6. 边界应自然融合，可通过颗粒渐疏、明暗延续、材质方向或主体遮挡过渡。

## 印刷 / 网点

| 名称 | 适配方向 | 视觉特征 |
|---|---|---|
| 柔和网点 | 人物、街景、建筑、编辑感照片 | 中等圆点或椭圆点，密度随明暗变化，边缘不过硬 |
| 中等半调 | 运动、城市、建筑、纪实 | 半色调结构清楚但不过粗，远看仍保留原场景关系 |
| 丝网网点 | 建筑、运动、海报感场景 | 网点略有印刷手感，边缘轻微不规则，不做巨大网点 |
| Riso 孔版颗粒 | 旅行、生活、编辑、植物 | 柔和孔版质感，轻微错位与油墨不均，但不做明显故障感 |
| 报纸细粗过渡 | 纪实、城市、人物群像 | 介于细网点与粗网点之间，整体克制，保留新闻印刷气息 |
| 油墨轻缺失 | 墙面、建筑、道路、平面背景 | 局部油墨密度不均、轻微缺墨，不形成大面积破损洞块 |

## 自然 / 矿物

| 名称 | 适配方向 | 视觉特征 |
|---|---|---|
| 柔砂颗粒 | 沙地、墙体、道路、水岸、自然景物 | 中等砂粒感，密度均衡，不做粗砾石大块 |
| 矿物细粒 | 岩石、建筑表皮、混凝土、山体 | 细至中等矿物颗粒，颜色受原材质与方案色控制 |
| 石墨颗粒 | 黑白、低饱和、建筑、人物 | 柔和石墨粉末与颗粒混合，方向性轻微，不脏乱 |
| 纸浆纤维颗粒 | 文艺、档案、生活、植物 | 纤维与细颗粒自然混合，纹理存在但不抢主体 |
| 微晶颗粒 | 水面、玻璃、冰雪、清冷场景 | 小至中等晶点，透明度受控，不出现大晶块 |
| 釉面细粒 | 建筑、器物、城市夜景 | 轻微釉面反光与颗粒起伏，不做彩窗或碎瓷大块 |

## 柔和 / 光学

| 名称 | 适配方向 | 视觉特征 |
|---|---|---|
| 雾化颗粒 | 天空、水面、远景、柔和人物场景 | 颗粒边界较软，与雾化明暗自然融合，不等于模糊整图 |
| 柔焦颗粒 | 人像、植物、静物、生活记录 | 中等颗粒与轻柔光晕结合，避免梦幻方块和泡泡感 |
| 银盐颗粒强化 | 纪实、黑白、胶片气质 | 比普通胶片颗粒更可见但仍自然，不做粗大噪点 |
| 纸面印刷颗粒 | 编辑、杂志、建筑、产品 | 纸张微纹理与中等印刷颗粒结合，整体干净克制 |

## 自动选型建议

- **天空 / 水面 / 远景**：优先 `雾化颗粒`、`柔和网点`、`微晶颗粒`。
- **建筑 / 墙面 / 混凝土**：优先 `矿物细粒`、`丝网网点`、`纸面印刷颗粒`。
- **道路 / 场地 / 运动背景**：优先 `中等半调`、`柔砂颗粒`、`丝网网点`。
- **人物周边背景 / 生活场景**：优先 `柔和网点`、`Riso 孔版颗粒`、`柔焦颗粒`。
- **纪实 / 黑白 / 档案**：优先 `报纸细粗过渡`、`银盐颗粒强化`、`石墨颗粒`。
- **植物 / 自然 / 乡野**：优先 `纸浆纤维颗粒`、`柔砂颗粒`、`柔焦颗粒`。

## 禁止自动选择的方向

本 Skill 不使用以下颗粒语言作为自动或内置预设：

- 大方块 / 大像素；
- 拼豆 / 串珠 / 毛毡球；
- 巨大马赛克砖 / 彩窗大块；
- 梦幻方块 / 玻璃方块；
- 巨型 Voronoi / 巨型低多边形；
- 糖果 / 玩具 / 泡泡式夸张颗粒；
- 巨大厚涂块 / 大面积撕纸块；
- 任何单颗粒尺寸明显压过主体或场景结构的效果。
