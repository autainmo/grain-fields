# Art Direction

本文件负责最终视觉方案：四方案结构、分区配色、核心大颗粒区、主体轮廓、文字、比例与预设库。其他文件不得重新定义这些细节参数。

## 1. 四方案结构

默认一次生成 4 个完整方案：

- **方案 1**：独立配色方向 A；
- **方案 2**：独立配色方向 B；
- **方案 3**：独立配色方向 C；
- **方案 4**：原图配色 + 大颗粒。

方案 1–3 必须从主体、背景内容、故事性、情绪、光线与文字关系出发重新设计，**不得被原图现有配色牵制**。三者应在冷暖、明暗、饱和度、对比方式和情绪气质上形成明显不同的视觉赛道，不能只是近似色替换。

方案 4 必须保留原图主配色、构图、主体位置、比例和景物关系，只允许做不改变综合色关系的质感、饱和度、对比度和清晰度优化，并执行相同的背景分区、大颗粒与主体轮廓规则。

## 2. 背景分区配色

### 2.1 分区来源

背景只能使用 `01-scene-analysis.md` 已确认的 2–3 个内容区域。

每套方案都必须是一个**完整的多区域配色方案**，即同时明确：

- R1 的主色 / 明度 / 饱和度角色；
- R2 的主色 / 明度 / 饱和度角色；
- R3（若存在）的主色 / 明度 / 饱和度角色；
- 主体保留色；
- 文字色；
- 必要强调色。

不能只给一个“主色”然后让所有背景区域统一染色。

### 2.2 主体颜色避让

方案 1–3 的大面积背景色与主要强调色应尽量避开主体自身最明显的固有色。

目的不是把主体改色，而是避免背景与主体融成一片。

若主体的标志性色彩对身份识别至关重要：

- 主体内部保留该颜色；
- 背景尽量使用对比、邻近偏移或中性色建立分离；
- 不为了“统一色调”抹掉主体重要颜色。

### 2.3 三方案差异检查

方案 1–3 至少在以下三项中的两项显著不同：

- 冷暖方向；
- 明度结构；
- 饱和度结构；
- 综合色相族；
- 对比方式；
- 情绪 / 叙事方向。

若三案仅是“红换橙、蓝换青”之类轻微变化，视为失败。

## 3. 核心大颗粒区域

### 3.1 每张图必须存在

**四个方案无一例外，都必须有一个明显的大面积粗颗粒区。**

### 3.2 区域大小

- 必须选择一整块连续、完整的背景内容区域；
- 原则上约占整幅画面的 **1/3–1/2**；
- 当画面内容允许时可更大；
- 不得只选边角、窄条、小色块或碎片化区域；
- 不得把大颗粒拆散到多个区域平均铺开。

若某一自然内容区本身小于 1/3，但它是最合适候选：

- 优先重新评估是否可与语义连续的相邻背景内容归为同一区；
- 不得跨越完整主体强行扩张；
- 若仍无法满足，选择下一面积更大且可承载的完整区域。

### 3.3 颗粒必须“大”且“明显”

目标是正常观看时第一眼就能看见独立颗粒结构。

执行特征：

- 使用粗颗粒、大网点、大尺寸半色调、粗印刷颗粒或等效结构；
- 可将单颗粒的视觉尺度理解为约占图像短边 **0.5%–2.5%** 的明显结构单元，具体随内容调整；
- 远看形成完整材质块面，近看能辨认颗粒单元；
- 颗粒密度随原区域明暗变化，但整体覆盖连续；
- 允许混合少量更细纹理作为过渡，但不能以细噪点取代大颗粒。

### 3.4 不是滤镜

核心颗粒区应被**整体重构为颗粒语言**：

- 原区域大体轮廓、明暗、空间关系仍可辨；
- 微小照片细节被概括进颗粒结构；
- 不允许只在照片表面叠一层透明噪声。

### 3.5 与其他区域的关系

- 其他背景区保持相对干净或只用轻纹理；
- 形成粗—净、密—疏对比；
- 核心颗粒区尽量避开主标题与主要正文；
- 边界通过色彩延续、颗粒逐渐疏化、主体遮挡、内容结构自然过渡；
- 不做硬贴纸式矩形纹理块，除非原内容边界本身就是矩形结构。

### 3.6 大颗粒重构方案选择

核心颗粒区不仅要决定“在哪里”，还必须决定“用什么大颗粒语言重构”。

#### 用户指定

用户可直接指定一个或多个大颗粒预设：

- 只指定 1 种：默认四个视觉方案都使用该大颗粒语言，配色与排版仍各自独立；
- 指定 2–4 种：按用户顺序分配到方案 1–4；数量不足时，其余方案由 AI 自动匹配；
- 明确写出“方案 1 / 2 / 3 / 4 = 某预设”时，严格按映射执行；
- 用户使用自然语言描述类似效果时，应先映射到最接近的预设，不要求用户记住正式名称。

#### 自动选择

用户未指定时，每个方案根据以下因素独立选取大颗粒语言：

1. 颗粒区原始内容与材质：建筑、水面、天空、岩石、地面、植被、墙体等；
2. 区域内部是否有清晰结构、柔和渐变、规则几何或粗糙纹理；
3. 当前配色方案的气质与对比强度；
4. 主体与颗粒区的边界复杂度；
5. 文字区位置与整体留白；
6. 故事性：竞技、纪实、梦幻、自然、工业、生活、艺术等；
7. 大颗粒重构后是否仍能保留该区域的大体内容与空间关系。

自动模式应优先让四个方案在大颗粒语言上也具有可感知差异；在画面适配的前提下，通常至少使用 3 种不同的大颗粒预设。只有当某一种效果明显最适合多个方案时，才允许重复。

#### 适配倾向

- 建筑、墙体、城市结构：优先考虑印刷缺失、粗网点、超大半调、大方块马赛克、低多边形；
- 水面、天空、柔和光影：优先考虑梦幻方块、玻璃方块、气泡、Voronoi 晶格、点彩大颗粒；
- 岩石、礁石、粗糙地面：优先考虑粗砂、砾石、碎瓷马赛克、厚涂颜料块；
- 竞技场地、平整地面、强图形场景：优先考虑超大半调、粗网点、大像素、拼豆；
- 植被、花卉或装饰性背景：优先考虑拼豆、串珠、毛毡球、彩窗玻璃、撕纸碎块；
- 纪实 / 旧刊 / 印刷方向：优先考虑印刷缺失、缺墨斑块、粗网点、超大半调；
- 梦幻 / 轻盈 / 数字方向：优先考虑梦幻方块、玻璃方块、大像素、气泡、Voronoi 晶格；
- 手工 / 拼贴方向：优先考虑拼豆、串珠、亮片、碎瓷马赛克、撕纸碎块、碎照片。

以上只是选型倾向，不是固定映射；最终仍以画面内容完整性和视觉协调为准。

### 3.7 完整大颗粒重构预设库

完整且唯一的预设清单存放在 [`presets-grain.md`](./presets-grain.md)。选型时必须从该文件读取，不得依赖模型记忆或本文件旧版摘要自行补全。

- 用户指定具体名称时：严格采用该名称对应的颗粒语言；
- 用户指定类别时：只在该类别内按区域内容选型；
- 自动时：先判定最适合的类别，再从完整清单中选具体预设；
- 默认四方案优先使用至少 3 种不同预设，并尽量跨类别，但内容适配优先于为了差异而强行换类。

## 4. 主体轮廓线

- 主要主体沿真实外缘描边；
- 默认 **纯白色**；
- 只有主体周围存在大面积白色或极浅色、白线失去区分度时，才改用当前方案中对比度足够高的单一颜色；
- 粗细根据主体尺寸、轮廓复杂度、背景密度和观看尺度自动判断；
- 轮廓必须明显，但不能粗到吞没人物五官、动物四肢、建筑边缘或器物细节；
- 不使用多层霓虹描边、发光描边、彩虹边等未要求效果。

## 5. 文字与信息排版

### 5.1 用户提供文本

- 用户填写了什么就合理展示什么；
- 未填写的事实字段不得编造；
- 可调整断行、字号、位置、字重、对齐与层级；
- 不得改变核心语义；
- 主文字优先位于干净区，不压在强颗粒区上。

### 5.2 用户未提供文本

每个视觉方案根据自身配色、主体、背景、故事性和留白**单独选择最适合的文本类型并自动创作**。

四张不要求使用同一文案；更应让文案与各自视觉方向匹配。

优先从完整文本预设库中选择适配赛道，例如：内容型 / 新闻型、打卡 / 摄影信息型、文学型、人物专题、档案型、旅行型、建筑 / 自然科普型、电影 / 编辑型、口号 / 宣言型等。

### 5.3 事实信息约束

地点、时间、相机、镜头、参数、人物身份、事件、天气、摄影者等属于事实信息。

- 用户提供：可用；
- 未提供：不能猜；
- 可以根据图片写非事实性描述，如“海风”“人群”“城市灯光”仅在画面可见时使用；
- 不得把推测写成具体地名、具体型号或具体日期。

## 6. 比例与构图

- 默认保持原图比例与主要构图。
- 用户明确指定载体、比例或平台时，才从完整比例预设库选择。
- 方案 4 默认不裁切、不改构图；只有用户明确要求统一比例时才可做最小必要裁切。
- 方案 1–3 在用户明确指定新比例时可重新安排文字留白，但主体结构与场景逻辑仍须保留。

## 7. 预设库使用规则

以下预设库是**高覆盖率路由库**，不是强制模板：

1. 先理解画面，再选预设；
2. 大颗粒预设、配色预设、文本预设和比例预设分别负责不同维度，不互相替代；
3. 方案 1–3 的配色应从不同赛道选型；自动模式下的大颗粒预设也应优先拉开差异；
4. 预设只规定方向，不允许覆盖主体保留、背景分区和大颗粒不变量；
5. 不得为了预设而进行季节替换、昼夜替换、天气替换、年代场景重建等大幅内容改动，除非用户明确要求；
6. 用户明确指定大颗粒 / 配色 / 文本 / 比例预设时，以用户指定为准。

## 8. 完整预设库路由

为保持 Art Direction 可执行且便于维护，完整预设分别存放于：

- `presets-grain.md`：完整大颗粒重构预设；
- `presets-color.md`：完整配色预设；
- `presets-text.md`：完整文本方案预设；
- `presets-aspect.md`：完整比例 / 载体预设。

需要选型时读取对应文件；这些预设只用于路由和发散，不得覆盖本文件前述固定艺术指导规则。

## 11. 选型原则

### 大颗粒重构

优先选择能够解释核心颗粒区原内容、同时与当前方案配色和故事性匹配的颗粒语言。用户指定时严格遵循；自动模式下先保证适配，再追求四案差异。任何预设都不得弱化“大区域 + 大颗粒 + 可辨原内容”的硬条件。

### 配色

- 方案 1–3 从不同赛道中选，优先跨类别组合。
- 若画面本身很强，不必选择最复杂的预设；可使用“原色保留强化”“局部灰调聚焦”等方法型配色。
- 如果主体自身颜色很强，背景大面积主色尽量绕开它。
- 所有方案仍要保留同一大颗粒结构原则。

### 文本

- 先判断用户是否提供文字与事实。
- 无文字时，每个方案可以选不同文本赛道。
- 不要固定死为“内容 / 打卡 / 文学”三类；应从完整预设库中选真正适配的类型。
- 需要事实但事实缺失时，换用不依赖事实的文本类型，而不是编造。

### 比例

- 默认原比例。
- 用户指定用途时才选。
- 方案 4 优先原比例。
