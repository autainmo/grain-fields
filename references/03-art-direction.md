# Art Direction

本文件负责最终视觉方案：四方案结构、分区配色、核心大颗粒区、主体轮廓、文字、比例与预设库。其他文件不得重新定义这些细节参数。

## 1. 四方案结构

默认一次生成 4 个完整方案：

- **方案 1**：独立配色方向 A；
- **方案 2**：独立配色方向 B；
- **方案 3**：独立配色方向 C；
- **方案 4**：原图配色 + 大颗粒。

方案 1–3 必须从主体、背景内容、故事性、情绪、光线与文字关系出发重新设计，**不得被原图现有配色牵制**。三者应在冷暖、明暗、饱和度、对比方式和情绪气质上形成明显不同的视觉赛道，不能只是近似色替换。

方案 4 必须保留原图主配色、构图、主体位置、比例和景物关系，只允许做不改变综合色关系的质感、饱和度、对比度和清晰度优化，并执行相同的背景分区、大颗粒与主体轮廓规则。

四个方案的配色类型都必须不同；方案 1–3 不得彼此重复，也不得与方案 4 的原图配色保留方向混同。默认执行时，配色类型应从适配当前图片的候选预设中随机选出 4 个不同方向，再从中组合出效果最好的四案，而不是固定重复使用同一套配色方案。

## 2. 背景分区配色

### 2.1 分区来源

背景只能使用 `01-scene-analysis.md` 已确认的 2–3 个内容区域。

每套方案都必须是一个**完整的多区域配色方案**，即同时明确：

- R1 的主色 / 明度 / 饱和度角色；
- R2 的主色 / 明度 / 饱和度角色；
- R3（若存在）的主色 / 明度 / 饱和度角色；
- 主体保留色；
- 文字色；
- 必要强调色。

不能只给一个“主色”然后让所有背景区域统一染色。

无论选择哪一种配色预设，背景重构后的综合色都必须保持干净、协调、有秩序；颜色数量、明暗层级与强调色关系要受控，不得出现杂乱、浑浊、脏灰或综合色失控的脏感。

### 2.2 主体颜色避让

方案 1–3 的大面积背景色与主要强调色应尽量避开主体自身最明显的固有色。

目的不是把主体改色，而是避免背景与主体融成一片。

若主体的标志性色彩对身份识别至关重要：

- 主体内部保留该颜色；
- 背景尽量使用对比、邻近偏移或中性色建立分离；
- 不为了“统一色调”抹掉主体重要颜色。

### 2.3 三方案差异检查

方案 1–3 至少在以下三项中的两项显著不同：

- 冷暖方向；
- 明度结构；
- 饱和度结构；
- 综合色相族；
- 对比方式；
- 情绪 / 叙事方向。

若三案仅是“红换橙、蓝换青”之类轻微变化，视为失败。

## 3. 核心大颗粒区域

### 3.1 每张图必须存在

**四个方案无一例外，都必须有一个明显的大面积粗颗粒区。**

方案 1–3 的核心颗粒区必须在 `01-scene-analysis.md` 给出的候选区域中，**分别结合当前方案的分区配色、明暗对比、文字留白、主体关系与视觉重心独立选择**。颗粒区是当前配色方案的一部分，不能先固定一个统一区域再让三套配色共用。若不同配色方向改变了视觉重心或颜色角色，应相应改选更匹配的背景区域。

方案 4 不参与上述重新设计逻辑，仍以原图配色与原构图关系为依据选择最合适的完整颗粒区。四个方案都应尽可能优先选择与主要主体直接相邻、紧挨主体的完整背景板块作为核心颗粒区；只有相邻区域明显不满足面积、连续性、主体安全、文字避让或当前方案适配时，才改选其他完整背景区域。若背景分区呈左中右、上中下或中心被外围包围的中间结构，则优先选择中间分区作为核心颗粒区。

### 3.2 区域大小

- 必须选择一整块连续、完整的背景内容区域；
- 原则上约占整幅画面的 **1/3–1/2**；
- 当画面内容允许时可更大；
- 不得只选边角、窄条、小色块或碎片化区域；
- 不得把大颗粒拆散到多个区域平均铺开。

若某一自然内容区本身小于 1/3，但它是最合适候选：

- 优先重新评估是否可与语义连续的相邻背景内容归为同一区；
- 不得跨越完整主体强行扩张；
- 若仍无法满足，选择下一面积更大且可承载的完整区域。

### 3.3 颗粒必须“大”且“明显”

目标是正常观看时第一眼就能看见独立颗粒结构，并在不破坏主体与场景关系的前提下让颗粒效果尽可能明显。

执行特征：

- 使用粗颗粒、大网点、大尺寸半色调、粗印刷颗粒或等效结构；
- 可将单颗粒的视觉尺度理解为约占图像短边 **0.5%–2.5%** 的明显结构单元，具体随内容调整；
- 远看形成完整材质块面，近看能辨认颗粒单元；
- 颗粒密度随原区域明暗变化，但整体覆盖连续；
- 允许混合少量更细纹理作为过渡，但不能以细噪点取代大颗粒。

### 3.4 不是滤镜

核心颗粒区应被**整体重构为颗粒语言**：

- 原区域大体轮廓、明暗、空间关系仍可辨；
- 微小照片细节被概括进颗粒结构；
- 颗粒效果覆盖整个选定分区，而不是只在该分区内部做局部颗粒块；
- 不允许只在照片表面叠一层透明噪声。

### 3.5 与其他区域的关系

- 其他背景区保持相对干净或只用轻纹理；
- 形成粗—净、密—疏对比；
- 核心颗粒区与主体之间保留清楚的视觉呼吸感，不让高密度颗粒紧贴、吞没或压迫主体轮廓；
- 核心颗粒区尽量避开主标题与主要正文；
- 边界通过色彩延续、颗粒逐渐疏化、主体遮挡、内容结构自然过渡；
- 不做硬贴纸式矩形纹理块，除非原内容边界本身就是矩形结构。

## 4. 主体轮廓线

- 主要主体沿真实外缘描边；
- 用户无明确要求时严格默认 **中粗纯白色单线**，不因背景颜色自动更换描边颜色；
- 只有用户明确指定其他描边颜色、粗细或形式时，才按用户要求调整；
- 用户未指定线宽时以中粗为默认基准，仅在避免吞没主体细节所必需时做小幅调整；
- 轮廓必须明显，但不能粗到吞没人物五官、动物四肢、建筑边缘或器物细节；
- 不使用多层霓虹描边、发光描边、彩虹边等未要求效果。

### 4.1 主体自身处理强度

- 用户未明确要求主体重构时，主体自身保持原图形、结构、比例、姿态、材质与关键辨识细节，不做明显风格化重构；
- 主体只允许轻微优化影调与颜色参数，例如小幅调整亮度、对比度、色温、饱和度或局部层次；
- 上述调整必须是微调，不得让主体呈现明显重新绘制、换材质、强烈改色或形态重塑的观感。

## 5. 文字与信息排版

### 5.1 用户提供文本

- 用户填写了什么就合理展示什么；
- 未填写的事实字段不得编造；
- 可调整断行、字号、位置、字重、对齐与层级；
- 不得改变核心语义；
- 主文字优先位于干净区，不压在强颗粒区上。

### 5.2 用户未提供文本

每个视觉方案根据自身配色、主体、背景、故事性和留白**单独选择最适合的文本类型并自动创作**。四个方案的文本类型都必须不同。默认执行时，文本类型应从适配当前图片的候选预设中随机选出 4 个不同方向，再从中组合出效果最好的四案；不得四张使用同一种文本形式。

四张不要求使用同一文案；更应让文案与各自视觉方向匹配。

优先从本文件“预设文本方案库”中选择适配赛道，例如：

- 内容型 / 新闻型；
- 打卡 / 摄影信息型；
- 文学型；
- 人物专题；
- 档案型；
- 旅行型；
- 建筑 / 自然科普型；
- 电影 / 编辑型；
- 口号 / 宣言型；
- 其他真实适配类型。

### 5.3 事实信息约束

地点、时间、相机、镜头、参数、人物身份、事件、天气、摄影者等属于事实信息。

- 用户提供：可用；
- 未提供：不能猜；
- 可以根据图片写非事实性描述，如“海风”“人群”“城市灯光”仅在画面可见时使用；
- 不得把推测写成具体地名、具体型号或具体日期。

## 6. 比例与构图

- 四个方案默认均保留原图尺寸与原图比例，不裁切、不改构图。
- 用户明确指定载体、比例或平台时，以用户指定为准。
- 只有用户明确指定尺寸，或当前任务明确要求其他输出尺寸时，才允许调用比例预设进行调整。

## 7. 预设库使用规则

以下预设库是**高覆盖率路由库**，不是强制模板：

1. 先理解画面，再选预设；
2. 方案 1–3 应从不同赛道选型，避免相邻路线；
3. 预设只规定方向，不允许覆盖主体保留、背景分区和大颗粒不变量；
4. 不得为了预设而进行季节替换、昼夜替换、天气替换、年代场景重建等大幅内容改动，除非用户明确要求；
5. 用户明确指定配色 / 文本 / 比例时，以用户指定为准。

## 7.1 再生成一组时的差异化与最优搭配

当上一组 4 张方案已经完成且用户选择“再生成一组”时：

- 直接重新设计 4 个方案，不要求用户再次确认；
- 新一组四案不得只是上一组的同色微调、颗粒区平移、文案换句或尺寸小改，而应在可调整维度上形成清晰的新组合；
- 设计时同时比较本轮此前已生成方案，优先避开已经使用过的综合色逻辑、颗粒区选择、文案方向和比例组合；
- 每次再次生成时，配色类型与文本类型仍应在适配候选中重新随机抽选，且四张内部都不得重复；
- 每个新方案仍以主体为中心，把**配色、颗粒选区、文案、尺寸**作为联动变量共同优化，而不是先分别随机选择再拼接；
- 用户可指定上述任意一项或多项。指定项视为硬约束，AI 不得擅自替换；未指定项必须围绕主体与指定项重新优化，使整套方案在可用候选中达到最优匹配；
- 用户未指定任何附加条件时，AI 全自动选择与前组不同且最适配主体的新组合；
- 方案 4 在用户没有明确覆盖其默认规则时，继续保留原图配色、构图与原比例，但应通过新的颗粒区、文案组织或其他允许变化的维度与前一组拉开差异。

### 8.11 方法 / 分区 / 保色

| 配色名 | 简介 |
|---|---|
| 局部灰调聚焦 | 背景分2–3区，一整块区域灰调，其他区保留原配色并优化质感、饱和度与对比度 |
| 灰彩对照 | 一部分区域压成黑白灰，另一部分保留强化彩色 |
| 单区去色 | 一个完整背景区域整体去色或大幅降饱和，其余彩色强化 |
| 局部冷却 | 一个区域转冷灰或冷色灰调，其余原色优化 |
| 局部暖压 | 一个区域转暖灰、棕灰或低饱和暖调，其余彩色强化 |
| 主区褪色 | 一大区域褪色旧化，其他区域更鲜明 |
| 彩灰叙事 | 灰调区域承载情绪，彩色区域承载信息焦点 |
| 局部静音 | 一个区域降饱和降对比，其他区域提升清晰和质感 |
| 焦点留彩 | 大部分区域中性化，保留一块鲜明彩度 |
| 双区异温 | 两个主要区域采用明显不同冷暖关系 |
| 三段递进 | 2–3区在明度或饱和度上逐步递进 |
| 同色系分层 | 同色系中用明度、纯度和质感分区 |
| 互补对冲 | 两个区域用互补色，第三个区域中和 |
| 邻近色过渡 | 各区域采用邻近色，整体和谐柔顺 |
| 高反差分区 | 不同区域在明暗和色相上形成强分区 |
| 低饱和分区 | 各区域控制低饱和，通过微妙色差建层次 |
| 暖区冷点 | 整体偏暖，局部一区转冷色或冷灰 |
| 冷区暖点 | 整体偏冷，局部一区转暖色或暖灰 |
| 光影分色 | 按受光、背光、阴影内容层进行配色区分 |
| 材质分色 | 按天空、岩石、植被、建筑、地面等材质内容分色 |
| 空间分色 | 按真实前景、中景、远景内容层做纯度或色温区分 |
| 情绪反转 | 主体周边与远处区域采用相反情绪色彩逻辑 |
| 纪实去艳 | 保留原综合色关系，但降低部分区域艳度 |
| 电影分区 | 按叙事功能给不同内容区安排氛围色 |
| 广告分区 | 颜色明确、分区清楚、对比强，强化主体信息 |
| 杂志分区 | 区域色彩服务版式和阅读性 |

| 原色保留强化 | 最大限度保留原图综合色，优化层次和通透度 |
| 单区颗粒强化 | 选一个完整大区域重点做大颗粒，其余保持干净 |
| 彩度失衡重构 | 有意拉开不同内容区彩度，形成视觉节奏 |
| 单区反相强调 | 一块完整区域采用反向综合色倾向，其余保持协调 |
| 黑白主体彩背景 | 主体保持黑白或低彩，背景各区分彩强化，需保持主体可辨 |
| 彩色主体灰背景 | 主体保留主要彩色，背景区域整体中性化并分层 |
| 原图色域压缩 | 不改综合色相，只压缩为更有限的色域和清晰层级 |
| 原图色域扩张 | 保持综合色逻辑，适度提升色差和层次但不改配色身份 |

## 11. 选型原则

### 配色

- 方案 1–3 从不同赛道中选，优先跨类别组合。
- 若画面本身很强，不必选择最复杂的预设；可使用“原色保留强化”“局部灰调聚焦”等方法型配色。
- 如果主体自身颜色很强，背景大面积主色尽量绕开它。
- 所有方案仍要保留同一大颗粒结构原则。

### 文本

- 先判断用户是否提供文字与事实。
- 无文字时，每个方案可以选不同文本赛道。
- 不要固定死为“内容 / 打卡 / 文学”三类；应从完整预设库中选真正适配的类型。
- 需要事实但事实缺失时，换用不依赖事实的文本类型，而不是编造。

### 比例

- 方案 1–3 分别结合各自配色方向、主体关系、文字留白和视觉重心独立选取最适合的比例，不统一套用。
- 方案 4 保留原比例。
- 用户指定用途或比例时，以用户指定为准。
