# Scene Analysis

本文件只负责理解用户上传图片与评估颗粒候选区，不负责最终配色和具体颗粒预设选型。

## 1. 分析目标

建立供后续重构使用的内部场景地图：

- 主要视觉主体与不可改变的识别信息；
- 2–3 个真实、连续的背景内容区域；
- 文字安全区；
- 每个背景区域的颗粒适配性；
- 哪个区域最适合自然颗粒化；
- 主体与背景的关键颜色关系；
- 故事性、情绪与用户事实字段。

## 2. 主体识别

综合判断视觉占比、清晰度、构图重心、光线、语义重要性、用户文字与故事核心。

记录：

- 类别 / 身份；
- 外轮廓；
- 结构比例；
- 姿态 / 朝向 / 动作；
- 关键材质与颜色；
- 遮挡和前后关系；
- 不可丢失的识别细节。

人物还需锁定五官辨识、发型、服装、姿势与人物数量。

## 3. 环境内容地图

先列出真实连续内容块，如：天空、水面、岩石 / 山体、植被、建筑、道路 / 地面、墙体、设备区、连续阴影或光照区等。

不要先按左 / 中 / 右或上 / 中 / 下切分；位置只能用于描述，不能作为分区理由。

## 4. 2–3 区域归纳

优先顺序：

1. 语义完整性；
2. 材质连续性；
3. 结构边界；
4. 空间层次；
5. 稳定的大面积明暗边界。

规则：

- 默认 2–3 个主要背景区域；
- 画面天然只有两个大背景层时不强行制造第三块；
- 小碎片不升级成独立主区域；
- 同一人物、动物、车辆、主要建筑、山体、器物或连续结构不得为分区而被拆开。

## 5. 文字安全区

识别 1–3 个候选文字区：

- 有连续留白；
- 不遮主体面部、建筑核心结构、动物头部、产品标识等；
- 与颗粒最密区尽量错开；
- 背景对比可保证可读；
- 与主体视线、运动方向或建筑线条关系自然；
- 不形成拥挤边角。

## 6. 颗粒候选区分析

在 2–3 个背景区域中逐一评分。**不要把面积最大直接等同于最适合。**

### 6.1 选择指标

- **语义完整性**：区域本身是否是自然成立的一块场景内容；
- **连续性**：是否成片、无碎裂；
- **材质适配**：颗粒化是否能顺着原有水面、墙体、地面、天空、岩石、植被等材质自然发生；
- **结构可保留性**：颗粒化后仍能辨认该区域大体轮廓、明暗与空间关系；
- **主体安全**：不会吞没主体或破坏关键边界；
- **文字避让**：不占主要文字最佳位置时优先；
- **视觉平衡**：能与主体形成层次，而不是抢掉主体；
- **自然融合潜力**：处理后看起来像画面材质的一部分，而不是贴上去的特效；
- **面积**：通常能承担整图约 1/4–1/2 的视觉面积即可，不以越大越好。

### 6.2 内部评分建议

每项 0–2 分：

- 语义完整性；
- 连续性；
- 材质适配；
- 结构可保留性；
- 主体安全；
- 文字避让；
- 视觉平衡；
- 自然融合潜力；
- 面积适中性。

其中**材质适配、主体安全、自然融合潜力权重最高**。总分最高且无硬冲突的区域优先。

### 6.3 颗粒尺度线索

只记录区域更适合：

- 中等规则网点；
- 中等不规则颗粒；
- 柔和颗粒；
- 矿物 / 纸面 / 印刷类颗粒；
- 明暗驱动的密度变化。

不要在本步骤直接确定具体预设，也不要提出大方块、拼豆、大像素、巨大马赛克等已禁用方向。

## 7. 色彩基础分析

记录：

- 主体最明显的 1–3 个固有色；
- 各背景区域原始主色；
- 综合色温；
- 主体与背景当前色差；
- 身份识别必须保留的颜色；
- 哪些背景颜色可自由重构。

供 `03-art-direction.md` 使用。自动配色应优先简洁、低干扰，不需要在本步骤追求多色发散。

## 8. 故事性与情绪

只从可见线索和用户输入提取，例如：纪实 / 克制、竞技 / 张力、自然 / 辽阔、建筑 / 理性、旅行 / 记录、文学 / 留白等；不凭空编剧情。

## 9. 用户文本与事实字段

地点、时间、相机、镜头、参数、人物身份、事件、天气、摄影者等属于事实字段：

- 用户提供：可用；
- 图片中可靠可见：只描述可见状态；
- 未提供且无法可靠确认：标记为不可生成事实。

标题、副标题、正文保留原意，不在分析阶段擅自改写。

## 10. 比例分析

默认保留原图比例。只有用户明确指定比例 / 载体 / 平台时，记录为 `aspect_ratio_constraint` 并交给 `03-art-direction.md`；方案 4 默认保留原构图和原比例。
