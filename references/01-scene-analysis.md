# Scene Analysis

本文件只负责理解用户上传图片，不负责决定最终配色与具体材质参数。

## 1. 分析目标

在不改变画面的前提下，建立可供后续重构使用的内部场景地图：

- 谁 / 什么是主要视觉主体；
- 哪些是次要主体与环境元素；
- 背景可以按哪些真实内容关系归纳为 2–3 个区域；
- 哪些区域适合承载文字；
- 哪个完整区域最适合成为大颗粒候选区；
- 主体自身最显著的颜色是什么；
- 画面可能具有怎样的故事性、情绪与信息属性；
- 用户输入的文字与事实字段如何影响后续设计。

## 2. 主体识别

### 2.1 主要主体判断依据

按以下信号综合判断：

1. 视觉占比；
2. 清晰度与对焦；
3. 位置与构图重心；
4. 光线和对比度；
5. 语义重要性；
6. 用户文字是否直接指向该对象；
7. 是否承担故事核心。

主体可以是：人物、群像、动物、建筑、山体、植物、车辆、器物、产品、船舶、雕塑、桥梁、水体、道路等。

### 2.2 主体锁定信息

记录：

- 类别 / 身份；
- 外轮廓；
- 结构比例；
- 姿态 / 朝向 / 动作；
- 关键材质；
- 关键颜色；
- 与环境的遮挡和前后关系；
- 不可丢失的识别细节。

若为人物，还需锁定：五官辨识、发型、服装、姿势与人物数量。

## 3. 环境内容地图

先列出画面中实际存在的连续内容块，例如：

- 天空；
- 海面 / 湖面 / 河流；
- 岩石 / 礁石 / 山体；
- 植被；
- 建筑群 / 单栋建筑；
- 道路 / 地面；
- 墙体 / 室内背景；
- 车辆群 / 设备区；
- 阴影或大面积光照区；
- 其他语义连续、材质一致的环境层。

不要先按“左、中、右”或“上、中、下”切分；位置只能用于描述，不能作为分区的唯一理由。

## 4. 2–3 区域归纳规则

### 4.1 分区优先级

优先按以下顺序归纳：

1. **语义完整性**：同类且连续的景物优先作为一个区域；
2. **空间层次**：前景 / 中景 / 远景只有在它们分别对应完整内容时才可用于分区；
3. **材质连续性**：水、石、天空、墙面、植被等材质差异可作为边界；
4. **结构边界**：建筑轮廓、地平线、道路边界、山脊等自然边界；
5. **明暗边界**：只有当大面积明暗本身形成稳定内容层时才使用。

### 4.2 完整主体不可拆分

以下情况不得为了凑 2–3 区而拆开：

- 同一个人物身体；
- 同一只动物；
- 同一辆车；
- 同一栋主要建筑；
- 同一座连续山体；
- 同一件器物；
- 同一主体中连续且不可分的结构。

如果一个主体跨越多个空间层，它仍然作为独立主体整体存在；背景区域从主体背后的环境内容中归纳。

### 4.3 区域数量

- 默认 2–3 个主要背景区域。
- 画面内容天然只有两个大背景层时，不强行制造第三块。
- 内容足够丰富时可使用三个，但不要把小碎片升级成独立主区域。

## 5. 文字安全区分析

识别 1–3 个候选文字区，按以下标准评分：

- 有足够连续留白；
- 不遮挡主体面部、眼睛、建筑核心结构、动物头部、产品标识等关键细节；
- 与颗粒候选区尽量错开；
- 背景对比可通过文字色保证可读；
- 能与主体方向、视线、运动方向或建筑线条形成自然版式关系；
- 不形成拥挤边角。

文字区不必固定为矩形，可顺应背景内容边界。

## 6. 核心颗粒候选区分析

先在 2–3 个背景区域中对每个区域评估：

### 6.1 选择指标

- **面积**：越大越优先，目标能承担约整图 1/3–1/2 的视觉面积；
- **连续性**：应是一整块连续内容，不是碎片；
- **内容特色**：区域本身有明显材质、明暗或图形特征；
- **可概括性**：即使细节被粗颗粒概括，主要轮廓仍可辨；
- **文字避让**：不承担主要文字时优先；
- **主体安全**：不会吞没主要主体或破坏关键边界；
- **主体邻接性**：尽可能优先选择与主要主体直接相邻、紧挨主体的完整背景板块；只有相邻区域明显不满足面积、连续性、主体安全或后续方案适配时，才降低其优先级；
- **视觉平衡**：能与主体形成重量平衡，而不是把画面压向一角；
- **呼吸感**：重颗粒后，其他区域仍能保留较干净空间。

### 6.2 内部评分建议

可内部使用 0–2 分：

- 面积：0 / 1 / 2
- 连续性：0 / 1 / 2
- 视觉特色：0 / 1 / 2
- 文字避让：0 / 1 / 2
- 主体安全：0 / 1 / 2
- 主体邻接性：0 / 1 / 2
- 平衡与呼吸：0 / 1 / 2

本阶段只形成**候选区及其评分**，不为方案 1–3 提前锁定同一个最终颗粒区。最终颗粒区由 `03-art-direction.md` 结合每个方案各自的配色、明暗结构、文字留白与视觉重心分别选择。

禁止仅写“选择最合适区域”而不依据以上条件判断，也禁止把同一个候选区直接默认套用到方案 1–3。

## 7. 色彩基础分析

记录但暂不决定方案：

- 主体最明显的 1–3 个固有色；
- 各背景区域的原始主色；
- 画面综合色温；
- 主体与背景的当前色差；
- 哪些颜色是身份识别所必需；
- 哪些背景颜色可在方案 1–3 中自由重构。

重要：方案 1–3 的后续配色不能被原图综合色限制；本步骤只用于避免与主体固有色冲突和判断方案 4。

## 8. 故事性与情绪分析

从以下线索中提取，不凭空编剧情：

- 主体动作与表情；
- 主体与环境的距离；
- 光线方向与天气；
- 场景类型；
- 是否存在事件线索；
- 用户填写的标题、主题、地点、时间或人物信息；
- 画面是纪实、旅行、竞技、建筑、自然、商业、生活还是其他属性。

最终只输出内部标签，例如：

- 纪实 / 克制；
- 竞技 / 爆发；
- 青春 / 轻快；
- 城市 / 冷峻；
- 自然 / 辽阔；
- 怀旧 / 私人；
- 建筑 / 理性；
- 旅行 / 记录；
- 文学 / 留白。

这些标签供 03-art-direction.md 选择差异化视觉赛道和文本类型。

## 9. 用户文本与事实字段分析

### 9.1 事实字段

地点、时间、相机、镜头、拍摄参数、人物身份、事件、天气、摄影者等属于事实字段。

- 用户提供：可用；
- 图片中可靠可见：可描述可见状态，但不要把推测当事实；
- 未提供且无法可靠确认：标记为“不可生成事实”。

### 9.2 自由文本

标题、副标题、正文属于用户自由文本：

- 保留原意；
- 分析语气、长度、关键词、情绪；
- 判断适合主标题、副标题、正文或注释的位置；
- 不在分析阶段擅自改写。

## 10. 比例分析

本阶段记录原图比例、主体占比、可扩展留白方向与可接受裁切边界，不为方案 1–3 提前锁定统一比例。

- 方案 1–3：由 `03-art-direction.md` 结合各自配色方向、明暗结构、文字留白、主体关系与视觉重心分别选择最适合的尺寸比例；不得默认三案统一使用原图比例或同一新比例。
- 方案 4：在没有用户明确要求时必须保留原构图和原比例。
- 用户明确指定比例或载体 / 平台时，按用户要求执行。
