### 8.11 方法 / 分区 / 保色

| 配色名 | 简介 |
|---|---|
| 局部灰调聚焦 | 背景分2–3区，一整块区域灰调，其他区保留原配色并优化质感、饱和度与对比度 |
| 灰彩对照 | 一部分区域压成黑白灰，另一部分保留强化彩色 |
| 单区去色 | 一个完整背景区域整体去色或大幅降饱和，其余彩色强化 |
| 局部冷却 | 一个区域转冷灰或冷色灰调，其余原色优化 |
| 局部暖压 | 一个区域转暖灰、棕灰或低饱和暖调，其余彩色强化 |
| 主区褪色 | 一大区域褪色旧化，其他区域更鲜明 |
| 彩灰叙事 | 灰调区域承载情绪，彩色区域承载信息焦点 |
| 局部静音 | 一个区域降饱和降对比，其他区域提升清晰和质感 |
| 焦点留彩 | 大部分区域中性化，保留一块鲜明彩度 |
| 双区异温 | 两个主要区域采用明显不同冷暖关系 |
| 三段递进 | 2–3区在明度或饱和度上逐步递进 |
| 同色系分层 | 同色系中用明度、纯度和质感分区 |
| 互补对冲 | 两个区域用互补色，第三个区域中和 |
| 邻近色过渡 | 各区域采用邻近色，整体和谐柔顺 |
| 高反差分区 | 不同区域在明暗和色相上形成强分区 |
| 低饱和分区 | 各区域控制低饱和，通过微妙色差建层次 |
| 暖区冷点 | 整体偏暖，局部一区转冷色或冷灰 |
| 冷区暖点 | 整体偏冷，局部一区转暖色或暖灰 |
| 光影分色 | 按受光、背光、阴影内容层进行配色区分 |
| 材质分色 | 按天空、岩石、植被、建筑、地面等材质内容分色 |
| 空间分色 | 按真实前景、中景、远景内容层做纯度或色温区分 |
| 情绪反转 | 主体周边与远处区域采用相反情绪色彩逻辑 |
| 纪实去艳 | 保留原综合色关系，但降低部分区域艳度 |
| 电影分区 | 按叙事功能给不同内容区安排氛围色 |
| 广告分区 | 颜色明确、分区清楚、对比强，强化主体信息 |
| 杂志分区 | 区域色彩服务版式和阅读性 |
| 展陈分区 | 不同区域承担不同信息角色，秩序克制 |
| 旧纸分彩 | 基于旧纸印刷综合色做区域色差 |
| 灰底跳色 | 大部分区域偏灰，仅部分区域高彩 |
| 雾化分彩 | 一区柔化灰化，另一区清晰鲜明 |
| 戏剧舞台 | 内容区像舞台布光一样承担不同色彩角色 |
| 叙事分幕 | 不同内容区像章节一样承担不同情绪 |
| 自然中性 | 保持原自然色，通过区域微调对比、纯度和明度 |
| 克制增强 | 不大改色相，只做区域化饱和、对比和清晰度强化 |
| 原色保留强化 | 最大限度保留原图综合色，优化层次和通透度 |
| 单区颗粒强化 | 选一个完整大区域重点做大颗粒，其余保持干净 |
| 彩度失衡重构 | 有意拉开不同内容区彩度，形成视觉节奏 |
| 单区反相强调 | 一块完整区域采用反向综合色倾向，其余保持协调 |
| 黑白主体彩背景 | 主体保持黑白或低彩，背景各区分彩强化，需保持主体可辨 |
| 彩色主体灰背景 | 主体保留主要彩色，背景区域整体中性化并分层 |
| 原图色域压缩 | 不改综合色相，只压缩为更有限的色域和清晰层级 |
| 原图色域扩张 | 保持综合色逻辑，适度提升色差和层次但不改配色身份 |
